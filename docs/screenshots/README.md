These are unedited melonDS 0.9.5 window captures made with normal controller
input on the Party CPU patch.

`5b86da28089a9c67c6978e584a4d36e5290a2337caca47193e1bb033d434265f`.

Character-select and match screenshots retain prototype 3 build SHA-256:

- `add-cpu.png`: Squad Leader after adding CPU 1 with DS X. The next player box
  reads X ADD CPU with left padding; there is no corner hint.
- `cpu-character-select.png`: choosing CPU 3, with the confirmed P1, CPU 1 and
  CPU 2 idle fighters still visible.
- `cpu-match.png`: Naruto in Battle Royale against Sasuke, Sakura and Shikamaru
  CPUs on Bamboo Grove, after ordinary movement and attack inputs.

The player-box label disappears when all three CPU slots are occupied. The native
wireless wording and Join artwork remain; no wireless guest is required.
